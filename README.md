# DeceptiveDocs

The official documentation site for **FRC Team 4392 — The Deceivers**. Built with [Docusaurus](https://docusaurus.io/), this site is the central hub for everything the team needs to design, build, wire, program, and maintain their robot.

## What's in here

- **Team** — roles, processes, and team resources
- **Software** — programming guides, code structure, and tools
- **Manufacturing** — machining, fabrication, and materials
- **Electrical** — wiring, motor controllers, sensors, and power distribution
- **Design** — CAD workflows and design standards
- **Build** — assembly instructions and robot documentation

## Local Development

Install dependencies (first time only):

```bash
npm install
```

Start the local dev server:

```bash
npm run start
```

This opens the site at `http://localhost:3000`. Most edits are reflected live without restarting.

## Build

Generate the static site for deployment:

```bash
npm run build
```

Output goes to the `build/` directory.

## Contributing

Documentation lives in the `docs/` folder as `.md` or `.mdx` files. To add or update a page:

1. Find or create the relevant file under `docs/`
2. Edit in Markdown — MDX (React components in Markdown) is supported
3. Run `npm run start` to preview locally before committing
